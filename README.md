# Toolkit — консольный калькулятор и конвертер величин

Лабораторная работа №1 по дисциплине «Программирование на языке Python».
Консольное приложение на `argparse`, объединяющее арифметический калькулятор и конвертер физических величин в единый пакет `toolkit`.

## Использование

```powershell
python -m toolkit calc "EXPRESSION" #Подсчет арифметического выражения
python -m toolkit convert VALUE --from UNIT --to UNIT #Конвертер величин
python -m toolkit --help #Вывод доступных команд
```

### Примеры

```powershell
python -m toolkit calc "23+4*3"
# 35.0

python -m toolkit calc "12 *    (12-9)"
# 36.0

python -m toolkit calc "30//7"
# 4.0

python -m toolkit calc "-33%12"
#3.0

python -m toolkit convert 5 --from cm --to m
# 0.05

python -m toolkit convert 0 --from c --to f
# 32.0
```

Выражение для `calc` нужно передавать в кавычках. Если выражение начинается с `-` (например, `"-5 + 3"`), программа распознаёт это как значение, а не как флаг, автоматически — писать разделитель `--` не требуется.

## Калькулятор

- Целые и вещественные числа.
- Операции `+`, `-`, `*`, `/`, `//`, `%`.
- Унарные `+` и `-` перед числом, в том числе повторные (`--5`).
- Скобки произвольной вложенности.
- Соблюдается приоритет `*`, `/`, `//`, `%` над `+`, `-`, левая ассоциативность одноуровневых операций.
- Пробелы в выражении игнорируются.
- Округление до 10 знаков после запятой.

## Конвертер

- Длина: `mm`, `cm`, `m`, `km`.
- Масса: `g`, `kg`.
- Температура: `c`, `f`, `k`.
- Регистр единиц измерения не учитывается.
- Конвертация допустима только внутри одной группы величин.
- Значения температуры ниже абсолютного нуля отклоняются.
- Полученное значение округляется до 10 знаков после запятой. 

## Обработка ошибок

Все ошибки вычислительного ядра выводятся в `stderr`, программа завершается с кодом `2`. Успешное выполнение — код `0`. Отдельные классы исключений заведены для: пустого выражения, недопустимого символа, пропущенного операнда, двух операторов подряд, непарных скобок, деления на ноль, некорректного числа, неизвестной единицы измерения, несовместимых единиц, значения вне допустимого диапазона.

## Реализованные дополнительные задания

- Скобки в арифметических выражениях (`recursive descent`, произвольная вложенность).
